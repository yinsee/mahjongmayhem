Mahjong Mayhem — Support

Mahjong Mayhem (麻将狂欢) is Chinese Official (Guobiao / MCR) mahjong on a bright 3D table for iPhone, iPad and Mac. It is free to play. Play against computer players, with friends on the same Wi-Fi, or online with Game Center.

How to play

  • Practice: play against three computer players. No account and no internet are needed.
  • Local Wi-Fi game: all devices must be on the same Wi-Fi. One player taps Host Local Game. The other players tap Join Local Game and select the room. The host can fill empty seats with bots and then starts the game.
  • Game Center: sign in to Game Center first. Game Center: Play with Friends lets you invite your friends. Game Center: Quick Match finds other players for you. A game has 2–4 players; bots fill empty seats.
  • To discard, tap a tile twice. When a Pong, Chow, Kong or Hu button shows, tap it or tap Pass.

Questions

The app asks for Local Network access. Why?
The app needs local network access to find and connect to other devices for Wi-Fi games. If you did not allow it, go to Settings › Privacy & Security › Local Network (Mac: System Settings › Privacy & Security › Local Network) and turn on Mahjong Mayhem. Practice and Game Center games do not need it.
How does voice chat work?
Voice chat is push-to-talk. Hold the microphone button to record a short voice message; release it to send. The message goes directly to the other players at your table. Voice is available only in Wi-Fi games and in Game Center games with invited friends. Quick Match and Practice never use the microphone. The app asks for microphone access the first time you hold the button. You can change this in Settings › Privacy & Security › Microphone.
I cannot play with Game Center.
Sign in to Game Center in Settings › Game Center (Mac: System Settings › Game Center), then open the app again. If a sign-in sheet shows in the app, complete it. All players need a Game Center account and an internet connection.
Which rules does the game use?
Chinese Official rules (Guobiao / MCR) with all 81 fans and flower tiles. The host can set a minimum fan count (0–16). The app has a fan table with example tiles for every fan, and the result sheet shows the tiles behind each fan.
Is there real money?
No. Points are for scoring only. There is no real money, no betting and no prizes.

麻将狂欢 — 支持

麻将狂欢（Mahjong Mayhem）是一款适用于 iPhone、iPad 和 Mac 的 3D 国标麻将（中国麻将竞赛规则）游戏，免费游玩。你可以与电脑对战、在同一 Wi-Fi 下与朋友联机，或通过 Game Center 在线对战。

玩法

  • 单机练习：与三位电脑玩家对战，无需账号，无需网络。
  • 局域网对战：所有设备需连接同一 Wi-Fi。一位玩家点“创建局域网房间”，其他玩家点“加入局域网房间”并选择房间。房主可用电脑补满空位，然后开始游戏。
  • Game Center：请先登录 Game Center。“Game Center 邀请好友”可邀请好友，“Game Center 随机匹配”会为你寻找其他玩家。每局 2–4 人，空位由电脑补上。
  • 出牌时点同一张牌两次。出现碰、吃、杠或胡按钮时，点按钮或点“过”。

常见问题

为什么应用要请求“本地网络”权限？
局域网对战需要通过本地网络查找并连接其他设备。如果之前没有允许，请前往“设置 › 隐私与安全性 › 本地网络”（Mac：“系统设置 › 隐私与安全性 › 本地网络”）打开麻将狂欢。单机练习和 Game Center 对战不需要此权限。
语音聊天怎么用？
语音为“按住说话”：按住麦克风按钮录制一条简短的语音消息，松开即发送，消息直接发给同桌的其他玩家。只有局域网对战和与受邀好友的 Game Center 对局可以使用语音；随机匹配和单机练习从不使用麦克风。首次按住按钮时，应用会请求麦克风权限，你可以在“设置 › 隐私与安全性 › 麦克风”中更改。
无法使用 Game Center 对战？
请在“设置 › Game Center”（Mac：“系统设置 › Game Center”）中登录，然后重新打开应用。如果应用中出现登录界面，请完成登录。所有玩家都需要 Game Center 账号和网络连接。
游戏使用什么规则？
中国麻将竞赛规则（国标 / MCR），包含全部 81 种番型及花牌，房主可设置起胡番数（0–16 番）。应用内有番种表并附示例牌，结算单会显示每个番种对应的牌。
涉及真实货币吗？
不涉及。分数仅用于计分，没有真实货币、下注或奖品。
